# mdcomputers-product-scraper
A Python web scraping project that extracts product details from the MDComputers website based on a search term. The script uses Requests and BeautifulSoup to fetch and parse product information such as product name, price, and product URL.
# MDComputers Product Scraper

## Installation
pip install -r requirements.txt

## Run
python scraper.py

The script searches MDComputers for a given search term and prints:
- Product Name
- Price
- Product URL
